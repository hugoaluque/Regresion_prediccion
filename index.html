Regresión Estadística y Modelos Predictivos Aplicados

De la exploración de relaciones bivariadas al ajuste, validación y predicción en Ciencias Ambientales y Forestales

Mientras que la inferencia clásica compara parámetros poblacionales entre grupos, el análisis de regresión establece relaciones funcionales entre una o más variables explicativas o predictoras (X) y una variable respuesta (Y), incorporando un término de error aleatorio (ε). Este enfoque permite estimar procesos biofísicos complejos (biomasa forestal, carga de sedimentos, eutrofización o riesgo de incendios) con cuantificación explícita de su incertidumbre.

Sección 01 • Fundamentos Matemáticos

Taxonomía y Tipos de Regresión Estadística

Selección de la estructura funcional según la naturaleza de la variable respuesta y la física del fenómeno estudiado.

Modelo de Regresión Forma Funcional Naturaleza de Y Aplicación Típica Ambiental / Forestal
Lineal Simple (OLS) Y = β0 + β1X + ε Continua lineal Relación turbidez vs. sólidos suspendidos (SST) o precipitación vs. escorrentía.
Lineal Múltiple Y = β0 + Σ βjXj + ε Continua aditiva Predicción de clorofila-a lacustre con índices espectrales, temperatura y fósforo.
Polinómica y Alométrica Y = a · Xb  /  β0 + β1X + β2X2 Continua curvilínea Ecuaciones alométricas de biomasa arbórea (AGB vs. DAP) y curvas altura-diámetro.
Logística Binaria P(Y=1) = [1 + e−(β0+β1X)]−1 Binaria (0 / 1) Probabilidad de ocurrencia de incendios forestales, mortalidad arbórea o presencia de especies.
Regularizada (Ridge / Lasso) Min [RSS + λ Σ |βj|q] Continua alta dim. Modelos con decenas de bandas satelitales (Sentinel-2/Landsat) altamente colineales.
1.1 Lineal Simple (OLS)

Mínimos Cuadrados Ordinarios

Estima los parámetros β0 (intercepto) y β1 (pendiente) minimizando la suma de cuadrados de los residuos Σ(yi − yi)2. La pendiente β1 representa el cambio esperado en Y por cada unidad de incremento en X.

Y = β0 + β1X + ε  |  β1 = Σ(xi − x)(yi − y) Σ(xi − x)2
1.2 Lineal Múltiple

Efectos Parciales y Multicolinealidad

Modela Y en función simultánea de k predictores. Cada coeficiente βj mide el efecto parcial de Xj manteniendo constantes las demás variables. Requiere vigilar la multicolinealidad mediante el Factor de Inflación de la Varianza (VIF < 5).

Y = β0 + β1X1 + β2X2 + … + βkXk + ε
1.3 Polinómica y Alométrica

Curvas No Lineales y Leyes de Escala

En dendrometría y ecología, el crecimiento sigue leyes potenciales (Y = aXb) que se linealizan mediante logaritmos naturales, o respuestas parabólicas de óptimo ambiental.

ln(Y) = ln(a) + b · ln(X)
1.4 Regresión Logística

Probabilidad de Eventos Binarios

Transforma combinaciones lineales en probabilidades acotadas en [0, 1] usando la función sigmoide. La exponencial eβ1 expresa el Odds Ratio (OR) o razón de momios.

P(Y=1) = 1 1 + e−(β0 + β1X)
1.5 Regularización (Ridge / Lasso)

Penalización y Prevención de Sobreajuste

Añade un término de penalización λ sobre la magnitud de los coeficientes: Ridge (L2) contrae coeficientes correlacionados; Lasso (L1) realiza selección automática llevando variables irrelevantes a cero.

LL2 = RSS + λ Σ βj2
Sección 02 • Rigor Estadístico y Validación

Diagnóstico, Supuestos y Métricas de Evaluación Predictiva

Un buen ajuste en la muestra de calibración no garantiza capacidad predictiva; se deben auditar los residuos y validar fuera de muestra.

2.1 R2 y R2 Ajustado

R2 mide la proporción de varianza de Y explicada por el modelo. En regresión múltiple se emplea R2adj porque penaliza la inclusión de predictores sin aporte real (k).

R2adj = 1 − (1 − R2)(n − 1) n − k − 1

2.2 Errores Predictivos (RMSE y MAE)

Evalúan la magnitud del error en las mismas unidades físicas de Y. El RMSE penaliza fuertemente errores atípicos grandes, mientras que el MAE es más robusto frente a valores extremos.

RMSE = √Σ(yi − yi)2n

2.3 Criterios AIC, BIC y Validación Cruzada

AIC y BIC equilibran verosimilitud y parsimonia (menor valor = mejor modelo). Para evitar el sobreajuste (overfitting), se divide la muestra (Train/Test) o se aplica Validación Cruzada k-Fold.

AIC = 2k − 2 ln(L)

2.4 Verificación de Supuestos Clásicos del Modelo Lineal (Acrónimo LINE)

La validez de los intervalos de confianza y pruebas de hipótesis (p-valores) depende del cumplimiento de cuatro propiedades sobre los residuos ei = yi − yi:

L

Linealidad

La relación media entre X e Y es lineal. En el gráfico de Residuos vs. Ajustados no deben verse arcos ni patrones curvos.

I

Independencia

Los errores son independientes entre observaciones (sin autocorrelación temporal o espacial). Se evalúa con el estadístico Durbin-Watson (≈ 2.0).

N

Normalidad

Los residuos siguen ε ∼ N(0, σ2). Se verifica mediante gráficos Q-Q y la prueba de Shapiro-Wilk (p > 0.05).

E

Equivarianza (Homocedasticidad)

Varianza constante de los errores en todo el rango de X (sin forma de embudo). Se contrasta con Breusch-Pagan.

Caso Python 01 Regresión Lineal Múltiple: Predicción de Clorofila-a Lacustre y Auditoría VIF
statsmodels OLS + VIF
Problemática Limnológica y Teledetección: Para monitorear procesos de eutrofización en cuerpos de agua altoandinos, se modela la concentración de Clorofila-a (μg/L) a partir del índice espectral satelital NDCI, la Temperatura superficial (°C) y el Fósforo Total (μg/L). Se evalúa la significancia individual (p-valores), el R2 ajustado y el Factor de Inflación de la Varianza (VIF) para descartar multicolinealidad severa.
Script en Python (Statsmodels OLS + Diagnóstico VIF) 
import numpy as np
import pandas as pd
import statsmodels.api as sm
from statsmodels.stats.outliers_influence import variance_inflation_factor

# 1. Dataset simulado de 20 estaciones de monitoreo lacustre
rng = np.random.default_rng(42)
n = 20
ndci = np.linspace(-0.05, 0.38, n) + rng.normal(0, 0.02, n)
temp = rng.uniform(11.5, 17.5, n)
fosforo_tot = 18 + 95 * ndci + rng.normal(0, 6.0, n)

# Modelo real: Chl-a = 4.5 + 62*NDCI + 0.65*Temp + 0.14*PT + error
chla = 4.5 + 62.0 * ndci + 0.65 * temp + 0.14 * fosforo_tot + rng.normal(0, 1.4, n)

df = pd.DataFrame({'NDCI': ndci, 'Temp': temp, 'Fosforo_Total': fosforo_tot, 'Chl_a': chla})

# 2. Ajuste OLS Múltiple
X = sm.add_constant(df[['NDCI', 'Temp', 'Fosforo_Total']])
modelo = sm.OLS(df['Chl_a'], X).fit()

# 3. Cálculo del Factor de Inflación de la Varianza (VIF)
vif_df = pd.DataFrame({
    'Variable': X.columns[1:],
    'VIF': [variance_inflation_factor(X.values, i) for i in range(1, X.shape[1])]
})

print(f"R² = {modelo.rsquared:.4f} | R² Ajustado = {modelo.rsquared_adj:.4f} | AIC = {modelo.aic:.2f}")
print("\nCoeficientes estimados:")
print(modelo.params.round(4))
print("\nDiagnóstico de Multicolinealidad (VIF):")
print(vif_df.to_string(index=False))

# 4. Predicción para un nuevo punto satelital/campo
nuevo_punto = pd.DataFrame({'const': [1.0], 'NDCI': [0.25], 'Temp': [15.0], 'Fosforo_Total': [42.0]})
pred = modelo.get_prediction(nuevo_punto).summary_frame(alpha=0.05)
print(f"\nPredicción Chl-a: {pred['mean'].iloc[0]:.2f} µg/L (IC 95%: [{pred['mean_ci_lower'].iloc[0]:.2f}, {pred['mean_ci_upper'].iloc[0]:.2f}])")

Caso Python 02 Regresión Alométrica No Lineal: Biomasa Forestal (Log-Log + Baskerville vs. curve_fit)
scipy.optimize.curve_fit
Problemática Dasométrica y Alometría de Carbono: Al retro-transformar modelos logarítmicos ln(Y) = ln(a) + b·ln(X) a escala aritmética (Y = a·Xb), se introduce un sesgo sistemático negativo que se corrige mediante el Factor de Corrección de Baskerville: CF = exp(MSElog / 2). Comparamos este enfoque frente al ajuste no lineal directo con mínimos cuadrados iterativos.
Script en Python (Alometría Forestal y Corrección de Sesgo) 
import numpy as np
from scipy.optimize import curve_fit

# 1. Datos de DAP (cm) y Biomasa Aérea Seca (kg) en plantación de Pinus patula
dap = np.array([7.5, 9.2, 11.0, 12.8, 14.5, 16.0, 18.2, 20.5, 22.8, 25.0, 27.4, 30.0])
agb = np.array([11.2, 18.5, 28.9, 41.0, 56.4, 71.8, 98.5, 132.0, 171.5, 215.0, 272.4, 341.0])

# 2. Enfoque A: Linealización Log-Log + Factor de Corrección de Baskerville
ln_x, ln_y = np.log(dap), np.log(agb)
b_log, ln_a = np.polyfit(ln_x, ln_y, 1)
mse_log = np.mean((ln_y - (ln_a + b_log * ln_x))**2)
cf_baskerville = np.exp(mse_log / 2.0)
a_corr = np.exp(ln_a) * cf_baskerville

# 3. Enfoque B: Regresión No Lineal Directa (Levenberg-Marquardt)
def modelo_alometrico(x, a, b):
    return a * np.power(x, b)

popt, _ = curve_fit(modelo_alometrico, dap, agb, p0=[0.1, 2.4])
a_nl, b_nl = popt

# 4. Comparación de RMSE en escala original (kg) y predicción para DAP = 32 cm
rmse_log_corr = np.sqrt(np.mean((agb - a_corr * dap**b_log)**2))
rmse_nl = np.sqrt(np.mean((agb - modelo_alometrico(dap, a_nl, b_nl))**2))

print(f"Log-Log Corregido : AGB = {a_corr:.5f} * DAP^{b_log:.4f} | CF = {cf_baskerville:.5f} | RMSE = {rmse_log_corr:.3f} kg")
print(f"No Lineal Directo : AGB = {a_nl:.5f} * DAP^{b_nl:.4f} | RMSE = {rmse_nl:.3f} kg")
print(f"Predicción DAP=32 : {modelo_alometrico(32.0, a_nl, b_nl):.2f} kg de biomasa aérea")

No Lineal Directo : AGB = 0.08982 * DAP^2.4231 | RMSE = 1.589 kg

Caso Python 03 Regresión Logística Binaria: Probabilidad de Incendios en Pajonales Altoandinos
statsmodels Logit + Odds Ratios
Problemática de Gestión de Riesgo Forestal: Para mapear la susceptibilidad a incendios de cobertura vegetal (Y = 1 ocurrencia; Y = 0 ausencia), se ajusta un modelo logístico binario en función del Déficit de Presión de Vapor (VPD, kPa) y la Distancia a vías/caminos rurales (km). Se calculan los Odds Ratios (OR) y el área bajo la curva ROC (AUC).
Script en Python (Regresión Logística, Odds Ratios y AUC-ROC) 
import numpy as np
import pandas as pd
import statsmodels.api as sm
from sklearn.metrics import roc_auc_score

# 1. Simulación de 120 puntos de monitoreo satelital de focos de calor
rng = np.random.default_rng(101)
n = 120
vpd = rng.uniform(0.4, 2.6, n)          # Déficit de presión de vapor (sequedad atmosférica)
dist_vias = rng.uniform(0.1, 8.0, n)    # Distancia a vías (km)

logit_p = -2.8 + 2.45 * vpd - 0.52 * dist_vias
prob_real = 1 / (1 + np.exp(-logit_p))
incendio = rng.binomial(1, prob_real)

df_fire = pd.DataFrame({'VPD': vpd, 'Dist_Vias': dist_vias, 'Incendio': incendio})

# 2. Ajuste del Modelo Logístico
X = sm.add_constant(df_fire[['VPD', 'Dist_Vias']])
logit_model = sm.Logit(df_fire['Incendio'], X).fit(disp=False)

# 3. Odds Ratios e Intervalos de Confianza
odds_ratios = np.exp(logit_model.params)
auc = roc_auc_score(df_fire['Incendio'], logit_model.predict(X))

print("Odds Ratios (exp(beta)):")
print(odds_ratios.round(3))
print(f"\nPseudo R² (McFadden) : {logit_model.prsquared:.4f} | AUC-ROC : {auc:.4f}")

# 4. Predicción de riesgo para día seco (VPD = 2.1 kPa) cerca de carretera (0.5 km)
escenario = pd.DataFrame({'const': [1.0], 'VPD': [2.1], 'Dist_Vias': [0.5]})
riesgo = logit_model.predict(escenario).iloc[0]
print(f"Probabilidad de incendio (VPD=2.1 kPa, Dist=0.5 km): {riesgo*100:.2f}%")
Salida de consola esperada:
Odds Ratios: const = 0.054, VPD = 12.418 (cada +1 kPa multiplica ×12.4 los momios), Dist_Vias = 0.581
Pseudo R² (McFadden) : 0.4412 | AUC-ROC : 0.9065

Caso Python 04 Flujo Predictivo Completo: Validación Cruzada k-Fold y Regresión Ridge (L2)
scikit-learn Pipeline + KFold
Problemática de Generalización y Prevención de Sobreajuste: Al predecir el Rendimiento Hídrico Específico (L/s·km2) de cuencas a partir de variables morfométricas y climáticas correlacionadas (precipitación, pendiente media, cobertura boscosa, índice de compacidad y altitud), un modelo sin regularización puede sobreajustarse. Implementamos un flujo profesional con StandardScaler, Ridge y Validación Cruzada 5-Fold.
Script en Python (Pipeline Scikit-Learn + Validación Cruzada) 
import numpy as np
from sklearn.model_selection import train_test_split, KFold, cross_val_score
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LinearRegression, Ridge
from sklearn.pipeline import make_pipeline
from sklearn.metrics import root_mean_squared_error, r2_score

# 1. Generación de 60 subcuencas con predictores correlacionados
rng = np.random.default_rng(7)
n = 60
pp_anual = rng.uniform(550, 1450, n)              # Precipitación (mm)
cob_bosque = rng.uniform(5, 75, n)                # Cobertura forestal (%)
pendiente = 12 + 0.015 * pp_anual + rng.normal(0, 4, n)
altitud = 4300 - 0.8 * pp_anual + rng.normal(0, 120, n)

X = np.column_stack([pp_anual, cob_bosque, pendiente, altitud])
y = 2.5 + 0.018 * pp_anual + 0.085 * cob_bosque - 0.06 * pendiente + rng.normal(0, 1.5, n)

# 2. División Train (80%) / Test (20%)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.20, random_state=42)

# 3. Pipeline Regularizado Ridge + Validación Cruzada 5-Fold
pipe_ridge = make_pipeline(StandardScaler(), Ridge(alpha=1.5))
cv = KFold(n_splits=5, shuffle=True, random_state=42)
cv_rmse = -cross_val_score(pipe_ridge, X_train, y_train, scoring='neg_root_mean_squared_error', cv=cv)

pipe_ridge.fit(X_train, y_train)
y_pred_test = pipe_ridge.predict(X_test)

print(f"RMSE Validación Cruzada (5-Fold): {cv_rmse.mean():.3f} ± {cv_rmse.std():.3f} L/s·km²")
print(f"RMSE en Conjunto de Prueba (Test): {root_mean_squared_error(y_test, y_pred_test):.3f} L/s·km²")
print(f"R² en Conjunto de Prueba (Test)  : {r2_score(y_test, y_pred_test):.4f}")

RMSE en Conjunto de Prueba (Test): 1.489 L/s·km²
